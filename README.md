# Chatbot IA con Spring Boot + Ollama

Proyecto de chatbot con streaming usando Spring Boot y Ollama (modelo phi).

## Tecnologías
- Java 17
- Spring Boot
- Ollama
- HTML + JS

## Cómo ejecutar

1. Ejecutar Ollama:
ollama run phi

2. Ejecutar el backend:
./mvnw spring-boot:run

3. Abrir en navegador:
http://localhost:8080/stream.html
